# Instagram Grid Preview

A powerful iOS app that helps users plan and preview their Instagram feed layout before posting. Built with SwiftUI and following Apple's design guidelines.

## Features

### 🎯 Core Features
- **Grid Preview**: Visualize how your photos will look on your Instagram profile
- **Drag & Drop Reordering**: Easily rearrange photos with automatic saving
- **Photo Management**: Add and delete photos seamlessly
- **Real-time Updates**: See changes instantly as you modify your grid

### ⭐️ Premium Features
- **Unlimited Grid Previews**: Plan your feed without limitations
- **High-Resolution Export**: Export your planned feed in high quality
- **Advanced Planning Tools**: Professional tools for better feed planning
- **Premium Filters**: Enhance your photos with exclusive filters

## Installation

1. Clone the repository
```bash
git clone https://github.com/mehmetkamay/InstagramGridPreview.git
```

2. Open the project in Xcode
```bash
cd InstagramGridPreview
open InstagramGridPreview.xcodeproj
```

3. Install dependencies (if any)

4. Build and run the project

## Usage

1. **Adding Photos**
   - Tap the "+" button to access your photo library
   - Select photos you want to add to your grid
   - Photos will appear in your preview grid

2. **Arranging Photos**
   - Long press and drag photos to reorder
   - Changes are saved automatically
   - Preview updates in real-time

3. **Premium Features**
   - Tap the star icon to access premium features
   - Purchase premium to unlock all features
   - Restore purchases if needed
